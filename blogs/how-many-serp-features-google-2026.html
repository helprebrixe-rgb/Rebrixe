How Many SERP Features Does Google Have in 2026?

By Rebrixe Team · July 24, 2026 · 10 min read

You run a rank tracker, see your page sitting at position 3, and expect steady clicks. Instead, traffic barely moves. So you search the keyword yourself — and above your listing sits an AI Overview, a People Also Ask box, a shopping carousel, and two other results with star ratings and thumbnail images. Position 3 isn't really position 3 anymore. It's somewhere past a wall of non-organic real estate that Google added without asking anyone's permission.

This is the reality of the modern SERP, and the question "how many SERP features does Google actually have" turns out to matter a lot more than it sounds. The answer changes how you plan content, how you read your rankings, and what "winning" a keyword even means in 2026.

Quick Answer

Google displays around 37 distinct SERP features in the US as of 2026, including AI Overviews, AI Mode, Featured Snippets, People Also Ask, Local Packs, Shopping carousels, and Knowledge Panels. That figure moves as Google tests and retires formats, so it's best treated as a current range rather than a fixed, permanent count.

What is a SERP feature?

A SERP feature is anything on a Google results page that isn't one of the traditional 10 blue links — including AI Overviews, Featured Snippets, Local Packs, and People Also Ask boxes. That covers a wide range of formats, from a plain text answer pulled straight out of a webpage to a full AI-generated summary sitting above every organic result, all designed to display something to the searcher as fast as possible.

  • The count is large and growing. As of 2026, Google displays 37 distinct SERP features in the US, including AI Overviews, AI Mode, People Also Ask, Featured Snippets, Things to Know, Shopping carousels, Local Pack, Video carousels, Top Stories, and Merchant Listings.
  • They now dominate the page. Together, these features occupy 60-80% of above-the-fold real estate on most commercial queries.
  • They're nearly universal. According to Semrush Sensor data from March 2026, only 1.16% of Google's first page results are without SERP features of any kind.
  • Not all features behave the same way. Some answer the query directly on the page (zero-click), while others make an organic-style listing more prominent without replacing the click entirely.

In short: a SERP feature is any enhancement layered onto the results page, and in 2026 there are dozens of them competing for the same screen space your organic listing used to have mostly to itself.

Why the SERP feature count matters

A high, still-climbing SERP feature count isn't trivia — it directly changes how SEO performance should be measured and planned:

  • Ranking position no longer equals visibility. A single search query might trigger a featured snippet, followed by video results, a People Also Ask box and organic shopping listings, meaning capturing the featured snippet position no longer guarantees top-of-page visibility, and neither does the number one organic ranking.
  • Zero-click search is now the norm, not the exception. Zero-click searches now account for over 50% of all Google queries, fundamentally changing how SEO professionals measure success.
  • The right features can boost clicks significantly. Rich results that include additional details such as ratings or images capture roughly 58% of all clicks, compared to 41% when no such enhancements are present.
  • Mobile changes which features you compete for. The mobile search experience has diverged further from desktop, with SERP features taking up larger portions of screen real estate.
📊 Quick stat Being ranked second on the SERP isn't what it used to be — a strong organic position can still sit below an AI Overview box, several ads, and a featured snippet, meaning visibility now matters as much as the ranking number itself.

Step-by-step: auditing SERP features for your keywords

  1. List your priority keywords. Start with the terms you already rank for or are actively targeting, grouped by intent.
  2. Search each one and log what appears. Note every feature above, beside, and interleaved with the organic results — not just the top result.
  3. Separate zero-click features from click-driving ones. Flag which features answer the query directly versus which ones enhance a listing that still gets clicked.
  4. Match content type to feature type. A list-based feature wants structured, scannable content; a Local Pack wants a business listing, not a blog post.
  5. Add the schema markup each feature depends on. The schema types with the most impact on visibility in 2026 are Organization, Person, Product, AggregateRating, FAQPage, and HowTo.
  6. Check mobile separately from desktop. Feature presence and layout can differ meaningfully between the two, especially for local and shopping queries.
  7. Re-check on a schedule, not once. Google adds and removes features often enough that a feature audit from six months ago may already be stale.

Common mistakes when tracking SERP features

1. Treating the feature count as fixed

Any published number, including the one in this guide, is a snapshot. Google tests new formats constantly, so a static list goes stale faster than most people expect.

2. Targeting a feature that doesn't match query intent

Trying to rank for a SERP feature without aligning content to the searcher's intent rarely works — a blog post won't win a Local Pack spot if the query is looking for nearby businesses, so content type always needs to match the feature being targeted.

3. Ignoring which features are zero-click

Knowledge cards and similar zero-click features can cause a significant drop in traffic for a query, since users get their answer without ever clicking through, so not every SERP feature win is a traffic win.

4. Skipping schema validation

Implementing schema without validating it through the Rich Results Test is a common reason structured data fails to produce the intended feature at all.

5. Only checking desktop results

Since most searches now happen on mobile and feature layout differs by device, a desktop-only audit can miss the features that actually matter most for a given keyword.

💡 Pro tip Log SERP features per keyword the same way you log ranking position — as a number that changes over time, not a one-off checklist item.

Real-world examples

How SERP features play out differently depending on query type:

Informational query
"What is the time in Tokyo"
Zero-click
A knowledge card answers the query instantly, and organic traffic for this type of search drops sharply as a result.
Recipe query
"Lasagna recipe"
Recipe carousel
Google displays recipe cards with images, ratings, and prep time pulled from multiple cooking sites at once.
Local query
"Plumber near me"
Local Pack
A map and three business listings dominate the top of the page, ahead of any organic blog or service page.
Product query
"Buy running shoes"
Merchant listings
Price and stock status appear directly in the snippet, letting shoppers compare before clicking through at all.

The pattern across all four: the feature that appears is dictated by intent, not by topic alone — the same brand can face an entirely different SERP landscape from one query to the next.

Zero-click vs. click-through SERP features compared

Not every SERP feature affects traffic the same way. Here's how the major categories differ.

Feature type Click impact Examples Watch out for
Zero-click answers Reduces clicks Knowledge cards, AI Overviews, direct answer boxes Query gets answered on-page; no click needed
Rich results Increases CTR Rich snippets, review stars, How-To results Requires accurate, validated schema markup
Commerce features Mixed Shopping carousels, Merchant Listings, product panels Can pre-qualify or pre-empt the click depending on intent
