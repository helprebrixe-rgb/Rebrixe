Tool limitations — read before converting
PNG output will be larger than the source JPG. PNG is lossless so files are typically 2–4× bigger. This is expected and cannot be avoided — it is the nature of the format.
Animated GIFs: first frame only. Only the first frame is converted. All animation data is permanently lost.
"Transparent" background does not remove image backgrounds. This option controls what colour (if any) is drawn on the canvas before your image. It does not remove or erase any part of the image. There is no background-removal feature in this tool.
Browser canvas limit: 16,384 × 16,384 px maximum. Using 2× scale on large images may exceed this and will fail with a clear error. Switch to 1× or 0.5× if that happens.
Maximum 20 files per session. Refresh the page to start a new batch.
Maximum 50 MB per file. Larger files may exhaust device memory, especially on mobile.
"Download All" creates a single .zip file containing all converted PNGs — not individual separate downloads.
Background colour options have no visual effect on plain JPG/BMP files. Those formats have no transparency. The background fill only makes a visible difference for WebP or GIF files that have transparent pixels.

About this converter

Why convert JPG to PNG?

PNG is lossless — every save is pixel-perfect. JPEG re-encodes on every save, degrading quality each time. Use PNG for logos, UI assets, screenshots, or anything you'll edit repeatedly.

Does PNG support transparency?

Yes — unlike JPG, PNG has a full alpha channel. But this tool does not remove backgrounds from photos. "Transparent" background means no fill colour is added to the canvas.

Why is my PNG file larger?

PNG stores every pixel without compression loss, so output is typically 2–4× bigger than the source JPG. That's the expected trade-off for lossless quality. For web use, consider WebP instead.

100% private, no server

All conversion runs in your browser's Canvas API. Nothing is uploaded. Works offline once the page is loaded. No account, no watermark, no file size tracking.
