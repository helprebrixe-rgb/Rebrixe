What this tool shows you

Frame count & duration

Total number of frames and the precise total playback duration in milliseconds. Useful for knowing if a GIF will feel snappy or sluggish.

Per-frame delay

Each frame in a GIF can have a different delay. The table shows every frame's delay so you can spot uneven timing or frames with 0ms delay (rendering issues).

Loop count

GIFs store a loop count via the Netscape extension. 0 means infinite loop. Some tools set this wrong — now you can verify.

Colour palette

GIF is limited to 256 colours per frame. Seeing the global palette helps diagnose banding and decide if a format switch (like WebP) would improve quality.
