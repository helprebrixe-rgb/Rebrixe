How it works

K-means colour clustering

Pixels are sampled and grouped into clusters. The centre of each cluster is the representative colour — the same method used by design tools and image editing software.

Percentage = actual pixel coverage

Each colour's share is calculated from real pixel counts, not guesses. The bar and percentages reflect exactly how much of your image each colour covers.

eCommerce colour tags

Every extracted colour is mapped to its nearest natural name (Crimson Red, Navy Blue, etc.) — ready to copy as product tags for Shopify, WooCommerce, or any catalogue.

100% private, zero upload

All processing runs in your browser via the Canvas API. Your images never touch a server. Works fully offline once the page loads.
