Why can't I open WebP files?

WebP isn't supported everywhere

Older Windows apps, many design tools, email clients, and iOS/Android apps don't render WebP. Converting to JPG makes images universally compatible.

Quality vs file size

Set quality to 85–92% for a great balance. Below 70% you'll see compression artifacts. Use 100% only if file size doesn't matter.

Transparent images (PNG)

WebP and PNG support transparency. JPG doesn't — choose a background fill color, or export as PNG to keep transparency intact.

100% private, works offline

Conversion uses the browser's built-in Canvas API. Nothing is uploaded anywhere. Works even without internet once the page loads.
