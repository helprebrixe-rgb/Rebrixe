How it works

Two levers, big results

GIF size is driven by two things: how many frames it has, and how many colors each frame uses. This tool lets you control both directly — no guesswork, no black-box settings.

See savings first

The estimator shows you approximate output size as you drag the sliders — before you run the compression. No surprises. If it's not enough, dial it down further.

Frame rate reduction

50% frames drops every other frame, halving animation data. Most GIFs still look smooth at 50–70%. Go lower for maximum compression on fast-moving GIFs.

100% private, zero upload

Everything runs in your browser using the Canvas API. Your GIF never touches a server. Works offline once loaded. No account, no watermark, no limit.
