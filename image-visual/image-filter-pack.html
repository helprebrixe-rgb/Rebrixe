What makes these filters different

Real pixel math, not CSS tricks

Every filter is computed directly on canvas pixel data — so what you see is exactly what gets downloaded. No surprises.

Intensity slider

Blend any filter at 30% Hint, 60% Subtle, or 100% Full. Most tools skip this and it makes a huge difference.

Hold to compare

Hold the button on the preview to instantly see your original. Release to go back. Fastest way to judge if a filter is working.
