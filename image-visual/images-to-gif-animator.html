How it works

Drag to reorder frames

Drag any frame thumbnail to a new position. The order you set is exactly what the GIF plays. Great for fixing accidental wrong file-order uploads.

Per-frame delay

Each frame has its own ms delay box. Use 100ms for smooth animation, 500–1000ms for slideshow-style presentations or animated diagrams.

Color quality vs size

GIF supports 256 colors. The Color Quality slider controls dithering accuracy — lower = smaller file, higher = better gradients and photos.

100% private, zero upload

The full GIF encoder runs in your browser using the Canvas API. Your images never touch a server. Works offline once the page is loaded.
