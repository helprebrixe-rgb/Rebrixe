When & how to use this

Prototyping & wireframes

Drop in placeholders while your real images aren't ready. Use the URL API directly in your HTML — no download needed, just update the size in the URL when you're ready.

Banner & ad mockups

The quick presets cover all standard IAB ad sizes — 300×250, 728×90, 160×600. Pick, color, download. Done in under 10 seconds.

OG image stubs

Need a quick 1200×630 placeholder for Open Graph while you design the real one? Hit the preset, copy the URL, paste into your <meta og:image> tag.

How the URL API works

The generated URL uses placehold.co — a public, free CDN. You can use it live in production for prototypes. Change the URL parameters to instantly swap size or color without re-downloading.
