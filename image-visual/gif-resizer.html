Why this GIF resizer is different

Animation stays intact

Every frame is decoded, resized individually, then re-encoded into a proper animated GIF. No frozen first frame, no broken loops.

Color palette control

GIFs max out at 256 colors per frame. Reducing the palette to 64–128 dramatically cuts file size while keeping the animation looking great.

Frame skip for tiny files

Set Frame Skip to 1 or 2 to drop alternate frames. Halves file size at the cost of a slightly choppier animation — great for email attachments.

100% private, zero upload

GIF is decoded and re-encoded entirely with the Canvas API in your browser. Your file never hits a server. Works offline once loaded.
