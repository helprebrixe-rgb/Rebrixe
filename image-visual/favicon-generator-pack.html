What's in the favicon pack?

                

                    

                        
favicon.ico — the classic

                        
The multi-resolution .ico file contains 16×16, 32×32 and 48×48 layers in one file. Every browser from IE to Safari reads it from your domain root automatically.

                    

                    

                        
PNG sizes — modern browsers

                        
16, 32, 48, 96, 128, 192, 256, 512px PNGs are generated. Chrome, Firefox, and Edge prefer high-res PNGs over .ico. 192 & 512 are required for PWA install prompts.

                    

                    

                        
Apple Touch Icon

                        
A 180×180px PNG apple-touch-icon.png for when someone adds your site to their iPhone home screen. Without it, iOS uses a screenshot — which looks terrible.

                    

                    

                        
manifest.json + HTML

                        
A complete manifest.json for PWA support, and ready-to-paste HTML tags for your <head>. Just copy, paste, and you're done — no guessing tag syntax.
