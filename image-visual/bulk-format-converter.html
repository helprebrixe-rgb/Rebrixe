Why this tool?

Batch convert, not one-by-one

Most free converters make you upload, convert, and download each file individually. This one does all 20 at once and hands you a single ZIP file.

WebP = 30% smaller

Converting to WebP typically saves 25–35% file size vs JPG at the same visual quality — great for web use, faster page loads, and tighter email attachments.

Max dimension option

Set a max dimension like 1280px and every image gets scaled down proportionally. Useful when sending a batch to a client or uploading to a CMS with size limits.

Zero upload, fully private

Everything runs on Canvas API inside your browser. Nothing is sent anywhere. No account, no watermark, no file size cap beyond what your browser RAM can handle.
