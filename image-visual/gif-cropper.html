How it works

All frames at once

Your GIF is decoded frame-by-frame in the browser. The same crop area is applied to every frame before the animation is re-encoded — so the loop stays perfectly intact.

Drag or type exact pixels

Drag the 8 handles to position your crop, or type exact X, Y, W, H values for pixel-perfect cuts. Great for aligning to specific UI elements.

Aspect ratio lock

Pick 1:1, 16:9, or any preset — the crop box locks to that ratio as you drag. Use Free for unrestricted cropping.

Reduce file size too

Crop removes pixels you don't need — smaller canvas = smaller file. Combine with the Colors option to shrink the palette and cut file size further.
