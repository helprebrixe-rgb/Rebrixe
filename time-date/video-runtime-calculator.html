Tool Limitations & Fixed Assumptions
› Platform limits are hardcoded — YouTube Shorts (60s), Instagram (90s), TikTok (10m), X/Twitter (2m20s), LinkedIn (10m). These are approximate, platform-enforced maximums as of mid-2024 and may change without notice. Always verify with the platform before publishing.
› Maximum single session total: 99 hours, 59 minutes, 59 seconds. Values beyond this will display but are not designed for edge cases beyond that.
› No data is saved between sessions. Refreshing the page clears all clips. There is no export, save, or sync feature.
› MM and SS fields only accept 0–59. Values outside this range are rejected in place. If you need to enter e.g. 90 seconds, use 1 minute 30 seconds instead.
› Bulk paste accepts whole seconds only. Sub-second precision (e.g. 1:23.456) is not supported — fractional values are ignored.
› "Copy Runtime" requires browser clipboard permission. If your browser blocks clipboard access, the button shows a fallback message so you can copy manually.
