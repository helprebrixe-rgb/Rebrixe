Weekly Timesheet
ⓘ What this tool does & doesn't do — read before using
  • Same-day shifts only. Start and end times must be on the same calendar date. Overnight/cross-midnight shifts (e.g. 22:00 → 06:00) are not supported — the row will show an error.
  • Overtime is per-day. OT is calculated as hours worked past your threshold on each individual day, not weekly cumulative hours. If your contract defines OT as >40 hrs/week, this tool's OT figure will differ.
  • Overtime rate is fixed at 1.5×. Double-time, holiday pay, or custom multipliers are not supported.
  • Break deduction is manual. You enter break minutes per day yourself. The tool does not auto-assume any break. If you leave the break field blank, zero break is deducted.
  • No data is saved. Refreshing or closing the tab clears everything. There is no multi-week history. Export to CSV before closing if you need a record.
  • Gross pay only. Tax, national insurance, superannuation, or any other deduction is not calculated. The figure shown is pre-tax gross.
  • Currency symbol is display-only. Changing the currency selector changes the symbol shown — it does not convert amounts.
