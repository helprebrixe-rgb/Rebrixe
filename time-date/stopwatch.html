⚠ What this tool does not do
  • No background timing: If you close or reload this tab, all lap data and the running timer are permanently lost. There is no session persistence.
  • Display precision is centiseconds (1/100 s), not milliseconds (1/1000 s) — the internal clock is accurate to the millisecond, but we display only 2 decimal places. Sub-centisecond differences are not shown.
  • Copy to clipboard requires HTTPS and browser permission. On HTTP or if permission is denied, Copy will show an error. Use .txt or .csv export instead.
  • Laps cannot be rearranged or edited after they are recorded. To correct a mistake, use Clear Laps.
  • No countdown or target time. This is a forward-only stopwatch.
