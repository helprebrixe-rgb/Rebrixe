What this tool does — and doesn't do
  • Fixed city list. This tool shows exactly 12 hardcoded cities. You cannot add, remove, or swap them out.
  • No DST guarantee during ambiguous hours. During "fall back" nights (e.g. 1:00–2:00 AM in affected zones), the same wall-clock time occurs twice. The tool picks the first occurrence (pre-transition). This affects a one-hour window, once or twice a year, per affected zone.
  • UTC offset labels are browser-supplied. Depending on your OS and browser, you may see "IST" or "GMT+5:30" for the same zone. The converted time is always correct; only the label style may differ.
  • Clipboard copy needs HTTPS. In some browsers, the Copy buttons require a secure (https://) connection. On plain http://, the copy will silently fall back to selecting the text instead.
  • No calendar file export. This tool does not generate .ics / Google Calendar / Outlook files. It only produces copyable text.
  • No duration support. You can only set a start time. Multi-hour webinar end times are not calculated.
