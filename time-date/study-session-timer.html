Study Session Timer

Set your subject, run focused sessions, track your whole study day — all in one place.

ⓘ Good to know before you start
  • Your data is saved only in this browser, on this device (local storage). Clearing browser data, using private/incognito mode, or switching browsers/devices will not carry your sessions over.
  • If this browser blocks local storage entirely, the timer still works, but nothing will be saved or restored — you'll see a warning toast if that happens.
  • The break reminder is a fixed 5 minutes — this can't be changed.
  • Custom duration is capped at 480 minutes (8 hours) and subject names at 40 characters.
  • Setup fields (subject, color, duration, break toggle) lock while a session is running, so the log always matches what you started.
  • If you reload or close the tab mid-session, your progress is restored when you come back — but only on the same calendar day. A session left running across midnight will be discarded (not logged) when reopened.
  • Don't run this tool in two tabs/windows at once — they don't sync, and the last one to save will overwrite the other's data.
  • There's no sound or push notification — completion is shown as an in-page message, so keep the tab open/visible to notice it (the countdown itself stays accurate even if the tab is in the background).
