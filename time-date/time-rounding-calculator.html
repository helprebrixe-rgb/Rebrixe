Tool limitations — read before use
  • Clock times only, not durations. Enter times like 09:30 or 14:45 — not elapsed time like 1h 23m. The tool rounds the minutes component of a wall-clock time.
  • No midnight crossing. If rounding 23:55 up by 15 min would cross midnight, the result is capped at 23:59. Overnight spans are not supported.
  • Batch total is a sum of minutes, not a duration span. It adds every raw time as absolute minutes (e.g. 09:00 = 540 min). This is useful only if all your entries represent equal-length time slots. It is not a start-to-end elapsed calculation.
  • Decimal hours use the same raw-minutes sum divided by 60. Same caveat as above applies.
  • No label/description per entry. Entries are anonymous time values. Export is plain text only — no CSV, no spreadsheet.
  • Copy to clipboard requires a secure context (HTTPS or localhost). On plain HTTP the copy button will show a fallback message.
Input mode
Format Time Picker uses your browser's native control. Type mode accepts HH:MM (24-hr or 12-hr with am/pm).
