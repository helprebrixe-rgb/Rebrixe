What this tool doesn't do — know before you use it
  • Frame count is a whole-frame approximation only. This is not drop-frame (DF) SMPTE timecode — it does not account for the 29.97 / 59.94 drift used in broadcast. For broadcast-accurate DF timecode, use professional NLE software.
  • Input is capped at 999,999,999 seconds (~31.7 years). Values above this are rejected.
  • Decimal seconds are accepted in Seconds and Minutes modes, but the HH:MM:SS inputs only accept whole numbers (hours, minutes, seconds must be integers).
  • In HH:MM:SS mode, minutes and seconds are not automatically clamped — entering 90 minutes or 75 seconds will still compute (it converts the overflow). However the inputs will show a validation warning.
  • Batch converter is only available in Seconds → Min/Hr and Minutes → Seconds modes, not in HH:MM:SS mode.
  • All number formatting uses a fixed period as the decimal separator regardless of your browser locale, so copied values are always machine-readable.
  • No timezone or calendar logic — this is pure duration arithmetic only.
