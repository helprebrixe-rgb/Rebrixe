⚠ What this tool does not do
  • Inputs are whole seconds only — sub-second (frames, milliseconds) are not supported.
  • Minutes and seconds fields are capped at 59. Hours are capped at 999. Values above these limits are clamped automatically and highlighted in amber.
  • Paste-to-split (importing a list of timestamps) has been removed — it was unreliable and is not available in this version.
  • Keyboard shortcut navigation between fields (arrow key / Enter jumping) has been removed — it was buggy and is not available in this version.
  • Format switching (e.g. HH:MM:SS → MM:SS) converts total seconds accurately, but the display is rounded to whole seconds — no fractional minutes.
  • Timecode shown in the frame count section assumes 0 sub-frame offset, as all inputs are whole seconds.
